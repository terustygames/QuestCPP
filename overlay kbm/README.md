# KBM Overlay — запись и воспроизведение ввода (макрос)

Оверлей клавиатуры/мыши (`overlay kbm/overlay.cpp`) теперь умеет записывать ввод
с таймингами и проигрывать его обратно через `SendInput` — например, чтобы
повторять трюк в Rocket League (флип-ресет,Musty и т.п.).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+R` | ⏺ Старт / стоп записи |
| `Ctrl+Shift+P` | ▶ Воспроизвести / остановить воспроизведение |
| `Ctrl+Shift+L` | 🔁 Вкл/выкл циклическое повторение (loop) |
| `Ctrl+Shift+H` | Показать/скрыть оверлей (было) |
| `Ctrl+Shift+M` | Переместить оверлей в другой угол (было) |
| `Ctrl+Shift+X` | Выход (было) |
| `F2` | Открыть окно настроек (было) |

Те же действия есть в окне настроек (F2) → секция **Recording (macro)**.

## Как пользоваться

1. Запусти игру (Rocket League), оверлей должен быть поверх окна.
2. Нажми `Ctrl+Shift+R` — вверху оверлея появится красная надпись `● REC …`.
3. Выполни трюк (все нажатия клавиш и кнопок мыши пишутся со временем).
4. Нажми `Ctrl+Shift+R` ещё раз — запись остановится и сохранится в
   `%APPDATA%\KBMOverlay\last.kbmrec`.
5. Нажми `Ctrl+Shift+P` — трюк проиграется ровно с теми же задержками.
   Повторное нажатие `Ctrl+Shift+P` остановит воспроизведение.
   `Ctrl+Shift+L` включает бесконечный повтор (удобно в free play).

Во время записи/воспроизведения оверлей продолжает подсвечивать нажатые
клавиши, а вверху показывает `● REC 3.2 s` или `▶ PLAY 1.5 / 4.0 s`.

## Технические детали

- Запись ловится в тех же low-level хуках (`WH_KEYBOARD_LL` / `WH_MOUSE_LL`),
  что и отображение. Собственные инжектированные события (`LLKHF_INJECTED`)
  в запись не попадают.
- Воспроизведение — отдельный поток с waitable-таймером (`timeBeginPeriod(1)`),
  события отправляются через `SendInput` в главный поток (`WM_APP+2`).
- При остановке записи из хвоста вырезается шум хоткея стопа (Ctrl+R), а все
  «зажатые» клавиши принудительно отпускаются в конце макроса, чтобы в игре
  ничего не залипло.
- Формат файла `last.kbmrec` — текстовый:
  `KBMREC1`, затем `count durationMs`, затем строки `<ms> K|M <vk> <down>`.
- Запись ограничена 5 минутами / 400 000 событий (автостоп).
