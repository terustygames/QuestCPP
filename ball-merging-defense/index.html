ОРБИТАЛЬ
Загрузка занимает больше времени, чем должна.
Чтобы играть: скачайте index.html из папки игры и откройте его двойным кликом в Chrome, Edge, Firefox или Яндекс.Браузере.
Это страница для разработки — игра с неё запускается только через dev-сервер Vite.
Запуск: в папке игры выполните npm install и npm run dev, затем откройте адрес вида http://localhost:5173/dev.html.
Просто поиграть: откройте файл index.html из той же папки — он уже собран, установка ничего не требуется.
