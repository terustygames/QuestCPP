# ОРБИТАЛЬ

Турбо-игра про оборону: соединяешь шарики — они стреляют во врагов,
которые идут по кольцевой трассе к выходу. Сделана для телефона
(портретная ориентация) и хорошо работает на компьютере.

Начинается с главного меню: «Играть», «Магазин», «Инвентарь». Колода
из шести шариков собирается в инвентаре; в забеге поле заполняется
только шариками колоды. Каждую пятую волну идёт босс: перед ним рулетка
выбирает, кто придёт — Громила или Стриж, — и даёт время подготовиться.

Дизайн простой и плоский: шарики — однотонные круги с тёмной кромкой
на тёмном фоне, без свечения и градиентов. Выбранный шарик подсвечен
белым кольцом, возможные цели для слияния — голубым.

## Как играть (установка не нужна)

1. Скачай файл `index.html` из этой папки (он один — всё внутри него:
   код, стили, шрифты, звуки).
2. Открой его двойным кликом в Chrome, Edge, Firefox или Яндекс.Браузере.
   На телефоне — перешли файл себе и открой в браузере.
3. Интернет не нужен.

Файл `index.html` создаётся командой `npm run build`. Его не надо
править вручную.

## Главное меню, магазин, инвентарь

- **Играть** — старт забега. Доступно, когда в колоде ровно шесть
  шариков. Перед стартом расходуются запасы из магазина (если куплены).
- **Инвентарь** — колода из шести шариков (тап — в колоду или из неё)
  и коллекция всех двенадцати типов. Зажми шарик — откроется окно
  с описанием и вкладкой «Дерево» (дерево навыков, его можно тянуть
  вверх и вниз, а в окне вниз прокручивается).
- **Магазин** — ежедневный сундук (раз в день, 60–150 монет и 1–3 очка
  прокачки) и покупки за монеты: открытие шариков (nova, stun, pierce,
  vampire, mark, barrage), запасы на забег (эссенция, жизни), открытие
  узлов дерева.

Валюта:

- **Монеты** — тратятся в магазине и на узлы деревьев. Начисляются
  по окончании забега: за каждую пройденную волну.
- **Очки прокачки (ОП)** — тратятся на узлы деревьев вместе с монетами.
  Начисляются по окончании забега: одно очко за каждую пройденную волну.

Пройденные волны в забеге — это волны, которые игрок закончил
(волна, на которой игра закончилась, не считается). Награда начисляется
при поражении и при «Завершить забег» в паузе.

## Дерево навыков

У каждого шарика своё дерево в стиле Outhold из 10 узлов с выбором.
Корень открыт всегда. От него две развилки A и B: открыть можно только
одну. Открытая развилка закрывает другую (узел становится «закрытым
выбором»). От выбранной развилки растут две ветки, и внутри неё можно
брать обе ветки свободно, по одному узлу тира 2 и тира 3 на ветку.
Стоимость тиров: 1/2/3 ОП и 40/80/150 монет. Эффекты узлов суммируются
и действуют на шарик, пока он стоит в колоде забега. Дерево сбрасывается
целиком: очки возвращаются полностью, монеты — наполовину, и тогда
можно выбрать другой путь.

## Боссы и рулетка

Каждая пятая волна — босс-волна. Перед ней во время подготовки
крутится рулетка: лента из двух боссов в случайном порядке
останавливается под стрелкой по центру, и босс под стрелкой приходит
в этой волне. У игрока есть время подготовиться.

- **Громила** (красный) — высокое здоровье и низкая скорость:
  готовь урон, накопление, сверхновые.
- **Стриж** (голубой) — стандартное здоровье и высокая скорость:
  готовь замедление льдом и паралич.

## Двенадцать типов шариков

Стартовые шесть: Огонь, Лёд, Молния, Яд, Шипастый, Усилитель.

- **Усилитель** — светлый шарик со звуковой волной: когда соседний
  шарик взрывается (игла шипастого или детонация сменой режима), он
  стреляет в два раза больше снарядов. Сам стреляет слабо, его сила —
  поддержка.

Дополнительные шесть (открываются в магазине за монеты):

- **Сверхновая** — взрыв: урон всем врагам в радиусе.
- **Паралич** — цель замирает на месте.
- **Пробой** — снаряд летит прямо и пробивает линию врагов.
- **Вампир** — урон плюс эссенция за попадание.
- **Метка** — ставит метки на случайных врагов. Метка жжёт врага и
  превращает урон в опыт самого шарика: растёт уровень типа «Метка».
- **Шквал** — залп из пяти снарядов.

Каждый тип имеет собственный знак на шарике, чтобы их было
различать.

## Управление

**Телефон:**

- Тап по шарику, затем по соседнему — действие (выстрел или слияние).
- Проведи линию по соседним шарикам (два и больше, зигзаги и углы
  разрешены) — каждый шарик на линии стреляет сразу. Проведённую
  линию видно голубой линией, над пальцем — счётчик шариков. Вернуть
  конец линии назад можно, просто проведя палец обратно.
- Протяни палец с одного шарика на соседний — то же самое одним движением.
- Держи шарик на поле нажатым около половины секунды — улучшение
  по типу: шарик исчезает, а уровень его типа в колоде внизу
  растёт. Каждое улучшение стоит 100 эссенции, лимитов нет.
- Зажми шарик в колоде внизу — откроется панель характеристик:
  что у типа сейчас, что повысится на следующем уровне и какие
  бонусы дерева навыков действуют.
- Тап по пустой клетке — поставить шарик бесплатно.
- Пустые клетки заполняются сами: каждые две секунды все пустые
  клетки получают новые случайные шарики.
- Кнопки внизу: смена режима (Совмещение/Накопление), досрочный
  вызов волны.

**Компьютер:**

- ЛКМ — выбрать / действовать, ПКМ — продать шарик (возврат эссенции).
- Пробел — режим, Enter — вызвать волну, P/Esc — пауза.

## Правила коротко

- Режим **Совмещение**: цепь — только из ОДИНАКОВЫХ шариков, исключение
  — шипастый: его можно соединить с любым шариком. Тапни по шарику и по
  соседнему того же типа, либо проведи линию по соседним шарикам
  (два и больше — зигзагом или буквой «Г», шипастые вставь куда нужно):
  каждый шарик на линии стреляет сразу по 2 снаряда, шипастые лопаются.
  Комбо-урон: каждый шарик в цепи добавляет +1 урона ко всем снарядам
  цепи (пара — +2). Сила выстрелов растёт вместе с уровнем типа,
  перезарядка — 1,3 секунды: дождись её и повтори ту же линию.
- Режим **Накопление**: одинаковые шарики сливаются в один (шипастый
  можно слить с любым шариком — заряд ляжет на тип второго нажатого),
  и уровни заряда складываются: шарик с уровнем 5 и шарик с уровнем 3
  дают шарик с уровнем 8 (максимум — 9). Заряд остаётся на шарике,
  нажатом вторым. Возврат в Совмещение — все заряженные лопают и
  выпускают залпы, сила которых растёт с уровнем. Урон залпа
  умножается на `1 + заряд × 0.02` (заряд 9 — ×1,18; заряд 1 — без
  бонуса). Множитель действует на все снаряды залпа и на иглы заряженного
  шипастого.
- **Колода** — панель в самом низу экрана: шесть шариков, из которых
  заполняется поле, и у каждого — уровень его улучшения (база — 1). Зажми шарик — откроется панель с
  характеристиками «сейчас / на следующем уровне».
- **Усилитель**: светлый шарик со звуковой волной. Когда соседний
  шарик лопается со залпом (игла шипастого или смена режима), рядом
  стоящий усилитель удваивает этот залп.
- **Шипастый**: соединяется с ЛЮБЫМ шариком (в паре, в цепи, в
  накоплении). В паре или цепи он не стреляет — лопается и выпускает
  четыре и более игл (уровень типа добавляет иглы; четыре главных
  направления всегда на месте — соседи достаются гарантированно).
  Игла разрушает первый шарик на пути и ранит первого врага, которого
  заденет (урон иглы растёт с уровнем шипастого).
  Шипастый под иглой — цепная реакция (четыре и более взрывов =
  бонус эссенции). Заряженный шарик (уровень заряда 2 и выше),
  лопнувший от иглы, стреляет залпом в размер заряда; обычный
  (уровень 1) просто лопается.
- **Улучшение — по типам**: зажми шарик на поле — он исчезает,
  а уровень его типа в колоде растёт (база — 1). Каждое улучшение
  стоит 100 эссенции, ограничений нет. Усиливается только этот тип:
  урон огня, силу и длительность замедления льда, длину цепи и радиус
  молнии, мощь яда, число игл и урон иглы у шипастого, радиус сверхновой,
  длительность паралича, число пробитых врагов, урон вампира, число и
  сила меток и размер залпа шквала. Точные цифры «сейчас / будет» — зажимом шарика
  в колоде.
- **Боссы**: каждую пятую волну. Рулетка перед волной выбирает, кто
  придёт: Громила (много здоровья, медленный) или Стриж (быстрый).
- Эссенция добывается за убитых врагов, зачистку волны, досрочный
  вызов и удары вампира; тратится только на улучшения.
- Враг дошёл до красной точки — минус одна жизнь (босс — минус пять).

## Для разработки (нужен Node.js)

Требуется Node.js 20.19+ или 22.12+. Проверка: `node -v`.

```
npm install
npm run dev      # http://localhost:5173/dev.html
npm run build    # собирает игру в index.html (и dist/index.html)
npm run preview  # http://localhost:4173 — посмотреть собранную игру
```

- `dev.html` — исходная страница для разработки (Vite).
- `index.html` — результат сборки, игровая версия.
- После правки кода пересобери: `npm run build`.

## Частые проблемы

- **Белая страница без текста** — открыт `dev.html` двойным кликом.
  Это страница разработки: нужен `npm run dev`. Для игры открой
  `index.html`.
- **В cmd пишет «npm не является командой»** — не установлен Node.js.
  Установи: `winget install -e --id OpenJS.NodeJS.LTS`, закрой окно
  cmd и открой новое, проверь `node -v`. (Для самой игры Node.js
  не нужен — только для правки кода.)
- **Игра не идёт в фоне** — при сворачивании вкладки игра ставится
  на паузу, чтобы враги не успели улизнуть.

## Технологии

React 19, TypeScript, Vite 7, Tailwind CSS 4. Сцена рисуется на
`<canvas>` (React только ведёт HUD), звук синтезируется WebAudio
(без файлов), шрифты Unbounded и Manrope упакованы внутрь файла
(@fontsource, SIL OFL).

```
index.html            собранная игра (один файл, играть)

  components/

    Shop.tsx          магазин: сундук, покупки, запасы

    BallModal.tsx     окно шарика: описание и дерево навыков
    GameStage.tsx     canvas-сцена + touch-управление
    Hud.tsx           шапка (волна/жизни/эссенция), кнопки, колода
    Overlays.tsx      помощь, конец забега с наградой
    BossRoulette.tsx  рулетка босса перед каждой босс-волной
    common.tsx        общие куски экранов: шапка, валюта, тосты
  game/
    config.ts         геометрия поля, трасса, баланс (все цифры тут)
    engine.ts         движок: волны, враги, снаряды, иглы, цепи
    skills.ts         деревья навыков шариков (все узлы и цифры)
    meta.ts           мета-прогресс: монеты, ОП, колода, сундук, награда
    audio.ts          синтез звуков WebAudio
  fonts.css           шрифты (cyrillic + latin)
  index.css           базовые стили
```
