# ОРБИТАЛЬ

Турбо-игра про оборону: соединяешь шарики — они стреляют во врагов,
которые идут по кольцевой трассе к выходу. Сделана для телефона
(портретная ориентация) и хорошо работает на компьютере.

## Как играть (установка не нужна)

1. Скачай файл `index.html` из этой папки (он один — всё внутри него:
   код, стили, шрифты, звуки).
2. Открой его двойным кликом в Chrome, Edge, Firefox или Яндекс.Браузере.
   На телефоне — перешли файл себе и открой в браузере.
3. Интернет не нужен.

Файл `index.html` создаётся командой `npm run build`. Его не надо
править вручную.

## Управление

**Телефон:**

- Тап по шарику, затем по соседнему — действие (выстрел или слияние).
- Протяни палец с одного шарика на соседний — то же самое одним движением.
- Держи шарик нажатым около половины секунды — улучшение (за эссенцию,
  стоимость растёт: 8, 16, 24, 32, максимум четыре уровня).
- Тап по пустой клетке — поставить шарик бесплатно.
- Пустые клетки заполняются сами: каждые две секунды в случайную
  клетку появляется новый шарик.
- Кнопки внизу: смена режима (Совмещение/Накопление), досрочный
  вызов волны.

**Компьютер:**

- ЛКМ — выбрать / действовать, ПКМ — продать шарик (возврат эссенции).
- Пробел — режим, Enter — вызвать волну, P/Esc — пауза.

## Правила коротко

- Режим **Совмещение**: два соседних шарика выстреливают. Разные типы —
  по 2 снаряда каждый.
- Режим **Накопление**: одинаковые шарики сливаются в один и получают
  уровень заряда. Возврат в Совмещение — все заряженные лопают и
  выпускают залпы, сила которых растёт с уровнем.
- **Шипастый**: при соединении лопается, 4 иглы ломают другие шарики,
  шипастый под иглой — цепная реакция (3 и более взрывов = бонус
  эссенции). Улучшенный шипастый выпускает до 7 игл.
- **Улучшение** усиливает конкретный шарик: огонь наносит до 6 урона,
  лёд замедляет дольше и сильнее, молния бьёт до 3 целей, яд действует
  мощнее и дольше.
- Огонь (урон и осколки), Лёд (замедление), Молния (цепь), Яд (поток
  урона).
- Эссенция добывается за убитых врагов, зачистку волны и досрочный
  вызов; тратится только на улучшения.
- Враг дошёл до красной точки — минус одна жизнь (босс — минус пять).
  Каждая пятая волна — босс.

## Для разработки (нужен Node.js)

Требуется Node.js 20.19+ или 22.12+. Проверка: `node -v`.

```
npm install
npm run dev      # http://localhost:5173/dev.html
npm run build    # собирает игру в index.html (и dist/index.html)
npm run preview  # http://localhost:4173 — посмотреть собранную игру
```

- `dev.html` — исходная страница для разработки (Vite).
- `index.html` — результат сборки, игровая версия.
- После правки кода пересобери: `npm run build`.

## Частые проблемы

- **Белая страница без текста** — открыт `dev.html` двойным кликом.
  Это страница разработки: нужен `npm run dev`. Для игры открой
  `index.html`.
- **В cmd пишет «npm не является командой»** — не установлен Node.js.
  Установи: `winget install -e --id OpenJS.NodeJS.LTS`, закрой окно
  cmd и открой новое, проверь `node -v`. (Для самой игры Node.js
  не нужен — только для правки кода.)
- **Игра не идёт в фоне** — при сворачивании вкладки игра ставится
  на паузу, чтобы враги не успели улизнуть.

## Технологии

React 19, TypeScript, Vite 7, Tailwind CSS 4. Сцена рисуется на
`<canvas>` (React только ведёт HUD), звук синтезируется WebAudio
(без файлов), шрифты Unbounded и Manrope упакованы внутрь файла
(@fontsource, SIL OFL).

## Структура

```
index.html            собранная игра (один файл, играть)
dev.html              исходная страница для npm run dev
src/
  App.tsx             компоновка, HUD-состояние, клавиатура, вибро
  components/
    GameStage.tsx     canvas-сцена + touch-управление
    Hud.tsx           шапка (волна/жизни/эссенция) и кнопки
    Overlays.tsx      экраны: заставка, помощь, конец игры
  game/
    config.ts         геометрия поля, трасса, баланс (все цифры тут)
    engine.ts         движок: волны, враги, снаряды, иглы, цепи
    audio.ts          синтез звуков WebAudio
  fonts.css           шрифты (cyrillic + latin)
  index.css           базовые стили
```
