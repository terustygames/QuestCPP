# C++ Quest — рабочие заметки

## Что было
- Один каталог `scripts/` с черновиком: HTML ссылался на `css/` и `js/`, которых не было;
  отсутствовали `progress.js` и `app.js`; интерфейс целиком строился на эмодзи.
- Задачи были тривиальными (вывести 42, сумма двух чисел), ожидаемые ответы никто не проверял.

## Концепт после переработки
Идея: **«Маршрут»** — C++ подаётся как линия метро. Каждая станция — ключевое слово или
конструкция, расположенные в порядке, в котором их обычно осваивает человек.
Пользователь отмечает станции, которые «уже проехал», и Арена подбирает задачи,
в которых нужны только известные конструкции (и подсвечивает «следующую станцию»,
если добавить одно новое слово — откроется N новых задач).

Атмосфера: «бумажная аркада» — тёплый кремовый фон, сочные плоские цвета
(коралл, солнечный, мята, фиолет), жёсткие тени, кнопки физически вдавливаются,
при клике летят искры, при верном решении — ленты и счётчик XP «набивается» как в слот-машине.
Никаких эмодзи: только SVG-иконки (`js/ui/icons.js`).

## Проверка задач
`node tools/validate_tasks.js` компилирует `solution` каждой задачи и сравнивает вывод
с `tests[].output`. Правило: задача не попадает в базу, пока валидатор не зелёный.

## Сравнение вывода
По умолчанию — построчно, с обрезкой хвостовых пробелов и пустых строк в конце.
Режим `tokens` — сравнение по токенам (для задач, где пробелы не важны).

## Статус
- 134 станции на 13 линиях, 73 задачи на 5 уровнях, все эталоны зелёные в валидаторе.
- Smoke-тест в jsdom проходит все экраны, победу, провал, ошибку компиляции без JS-ошибок.
- Главная предлагает «следующую станцию» по вкладу в почти открытые задачи (Store.nextStation).

## Оптимизация и «дрожание» (итерация 2)
Причины тряски: (1) `transform: translateY(-2px)` на hover — курсор у края элемента
попадает в петлю hover/unhover; (2) бесконечные `wobble`/`breathe` с rotate/scale на тексте —
перерастеризация шрифта каждый кадр; (3) `animation-fill-mode: both` у каскада спорил с transition.
Исправлено: hover теперь меняет только цвет/тень, бесконечные анимации сняты, класс `anim-rise`
снимается по `animationend`. Убраны `backdrop-filter`, шиммер оставлен только на большой полосе,
canvas частиц скрыт, когда пуст. Подсветка редактора и сохранение черновика — через rAF/debounce,
подсчёт «откроет N задач» кэшируется. Добавлен тумблер эффектов (data-motion="off").
