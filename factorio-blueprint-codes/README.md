# Извлечённые коды Factorio

Каждый файл `.txt` с кодом содержит одну строку экспорта Factorio, начинающуюся с `0`. Скопируйте всю строку и вставьте в игре через **Импорт строки**.

- `ideal-factory-book.txt` — книга «ИДЕАЛЬНАЯ ФАБРИКА».
- `krastorio-book.txt` — книга «KRASTORIO».
- `unnamed-book.txt` — книга без названия.
- `all-recovered-library.txt` — книга со всем, что удалось извлечь из старой библиотеки.
- `individual/` — отдельные элементы, в том числе вложенные книги и планировщики. Их номера и названия перечислены в `index.txt`.

## Ограничения

Коды получены из `Нужно достать все коды чертежей/blueprint-storage.dat` (библиотека Factorio 1.1) при помощи [factorio-blueprint-decoder](https://github.com/asheiduk/factorio-blueprint-decoder) с опцией пропуска ошибок. Из-за ошибок декодирования **11 чертежей пропущены**, в том числе один из книги «ИДЕАЛЬНАЯ ФАБРИКА» и один из книги «KRASTORIO». Коды этих книг и общей библиотеки неполные.

Строки проверены на обратное декодирование в JSON, но не проверялись в игре. Некоторые чертежи могут требовать соответствующие моды. Сохранение `Творческий эксперт — копия.zip` и библиотека `blueprint-storage-2.dat` при извлечении не использовались.
