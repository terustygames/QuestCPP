# Неоновая Осада — PvP Tower Defence на одной клавиатуре

Два игрока на одной клавиатуре: каждый строит башни на своей половине поля, собирает монеты и отправляет волны на базу соперника. У каждой базы 30 HP.

## Играть без установки

Готовая игра лежит в файле `play/neon-siege.html`. Установка Node.js не нужна.

1. Скачайте архив репозитория: на странице GitHub нажмите **Code → Download ZIP** и распакуйте его.
2. Откройте папку `local-pvp-tower-defense/play` и дважды щёлкните `neon-siege.html`.
3. Нажмите `Enter`, чтобы начать матч.

Подойдут Chrome, Edge, Firefox и Яндекс.Браузер. Файл самодостаточный: код, шрифты и звуки уже внутри него, внешние сайты не нужны.

## Для разработки (нужен Node.js)

### Что понадобится

- **Node.js 20.19+ или 22.12+** (LTS) — скачать на [nodejs.org](https://nodejs.org). Проверка: `node -v`.
- **Git** — для клонирования. Можно обойтись без него, см. ниже.

### Запуск с GitHub

Игра лежит в подпапке `local-pvp-tower-defense` репозитория `terustygames/QuestCPP`. В корне репозитория есть другой проект (папка `scripts/`, «C++ Quest»), он к игре не относится.

1. Получите код:

   ```bash
   git clone https://github.com/terustygames/QuestCPP.git
   cd QuestCPP/local-pvp-tower-defense
   ```

   Без Git: на странице репозитория нажмите **Code → Download ZIP**, распакуйте архив и откройте папку `local-pvp-tower-defense`.

2. Установите зависимости (нужно один раз):

   ```bash
   npm install
   ```

3. Запустите игру:

   ```bash
   npm run dev
   ```

4. Откройте в браузере адрес, который покажет терминал, обычно **http://localhost:5173**.

> **Не открывайте `index.html` двойным кликом.** Игре нужен запуск через сервер (Vite). Если открыть файл напрямую, игра не запустится: вместо пустой страницы вы увидите подсказку, как запустить проект правильно.

## Сборка в один файл

```bash
npm run build
```

Появится `dist/index.html`: весь код, стили и шрифты в одном файле, без запросов к внешним сайтам. Его можно открыть в браузере напрямую или выложить на любой хостинг. Чтобы обновить готовый файл для игры без установки, скопируйте `dist/index.html` в `play/neon-siege.html`.

Проверить собранную версию локально: `npm run preview`, затем открыть http://localhost:4173.

## Управление

| Действие | Игрок 1 (слева) | Игрок 2 (справа) |
| --- | --- | --- |
| Движение строителя | `W` `A` `S` `D` | стрелки |
| Башня: зажать — прицел, отпустить — построить | `Q` арбалет, `E` рельсотрон, `R` криоген | `,` арбалет, `.` рельсотрон, `/` криоген |
| Отправить волну | `F` | `Enter` (или правый `Shift`) |

Общие клавиши: `Esc` или `P` — пауза, `M` — звук. Окно, потерявшее фокус, ставится на паузу автоматически.

Строитель не выходит за свою зону строительства, поэтому граница видна сразу. Башню можно поставить, если хватает золота и место свободно: башня не должна стоять слишком близко к трассе, порталу, другим башням и базе.

## Частые проблемы

- **Белый экран или пустая страница.** Чаще всего файл открыт напрямую. Запустите `npm run dev` или откройте `dist/index.html` после `npm run build`.
- **`npm` не распознан: «не является внутренней или внешней командой» (Windows).** Node.js не установлен. Установите версию LTS с nodejs.org или командой `winget install -e --id OpenJS.NodeJS.LTS`, затем откройте новое окно терминала.
- **Ошибки при `npm install` или `npm run dev`.** Проверьте версию Node.js: нужна 20.19+ или 22.12+.
- **Порт 5173 занят.** Vite сам выберет свободный порт и напишет его в терминале. Можно указать явно: `npm run dev -- --port 5174`.
- **Экран с текстом «Игра не смогла отрисоваться».** Перезагрузите страницу. Подробности ошибки — в консоли браузера (`F12`).

## Технологии

React 19, TypeScript, Vite 7, Tailwind CSS 4. Игровое поле рисуется на Canvas 2D, звуки синтезируются через WebAudio (внешних аудиофайлов нет). Шрифты Unbounded и Rubik (лицензия SIL OFL 1.1) подключены из npm-пакетов `@fontsource-variable`, а не из Google Fonts.

## Структура

- `src/App.tsx` — меню, экран игры, оверлеи паузы и победы
- `src/game/engine.ts` — игровая логика и отрисовка
- `src/game/config.ts` — баланс, пути, клавиши, зона строительства
- `src/game/audio.ts` — звуковые эффекты
- `src/ErrorBoundary.tsx` — показывает ошибку вместо пустого экрана
- `src/fonts.css` — локальные шрифты
- `index.html` — стартовый экран загрузки и подсказка, если приложение не запустилось
