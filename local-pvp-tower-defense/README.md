# Неоновая Осада — PvP Tower Defence на одной клавиатуре

Два игрока на одной клавиатуре: каждый строит башни на своей половине поля, собирает монеты и отправляет волны на базу соперника. У каждой базы 30 HP.

## Как играть (установка не нужна)

1. Скачайте архив репозитория: на странице GitHub нажмите **Code → Download ZIP** и распакуйте его.
2. Откройте папку `local-pvp-tower-defense` и дважды щёлкните **`index.html`**.
3. Нажмите `Enter`, чтобы начать матч.

Подойдут Chrome, Edge, Firefox и Яндекс.Браузер. Интернет не нужен: код, шрифты и звуки уже внутри файла.

## Управление

| Действие | Игрок 1 (слева) | Игрок 2 (справа) |
| --- | --- | --- |
| Движение строителя | `W` `A` `S` `D` | стрелки |
| Башня: зажать — прицел, отпустить — построить | `Q` арбалет, `E` рельсотрон, `R` криоген | `,` арбалет, `.` рельсотрон, `/` криоген |
| Отправить волну | `F` | `Enter` (или правый `Shift`) |

Общие клавиши: `Esc` или `P` — пауза, `M` — звук. Окно, потерявшее фокус, ставится на паузу автоматически.

Строитель не выходит за свою зону строительства, поэтому граница видна сразу. Башню можно поставить, если хватает золота и место свободно: башня не должна стоять слишком близко к трассе, порталу, другим башням и базе.

## Для разработки (нужен Node.js)

Игра написана на React, TypeScript и Vite. Для правок кода нужен Node.js 20.19+ или 22.12+ (LTS).

```bash
git clone https://github.com/terustygames/QuestCPP.git
cd QuestCPP/local-pvp-tower-defense
npm install
npm run dev
```

- `npm run dev` запускает режим разработки. Откройте адрес из терминала с путём `/dev.html`, обычно http://localhost:5173/dev.html. Изменения в `src/` видны сразу.
- `npm run build` собирает готовую игру: обновляются `index.html` и `dist/index.html`.
- `npm run preview` открывает собранную версию на http://localhost:4173.

Правьте `dev.html` и папку `src/`. Файл `index.html` создаётся сборкой, вручную его не редактируют.

## Частые проблемы

- **Белый экран или надпись «Загрузка занимает больше времени».** Обновите страницу. Если не помогает, откройте `index.html` в Chrome, Edge, Firefox или Яндекс.Браузере.
- **Изменения в коде не видны в `index.html`.** Файл обновляется только командой `npm run build`. Для разработки откройте `/dev.html` из `npm run dev`.
- **`npm` не распознан (Windows): «не является внутренней или внешней командой».** Node.js не установлен. Установите версию LTS с nodejs.org или командой `winget install -e --id OpenJS.NodeJS.LTS`, затем откройте новое окно терминала.
- **Ошибки при `npm install` или `npm run dev`.** Проверьте версию Node.js: нужна 20.19+ или 22.12+.
- **Порт 5173 занят.** Vite сам выберет свободный порт и напишет его в терминале. Можно указать явно: `npm run dev -- --port 5174`.
- **Экран с текстом «Игра не смогла отрисоваться».** Перезагрузите страницу. Подробности ошибки — в консоли браузера (`F12`).

## Технологии

React 19, TypeScript, Vite 7, Tailwind CSS 4. Игровое поле рисуется на Canvas 2D, звуки синтезируются через WebAudio (внешних аудиофайлов нет). Шрифты Unbounded и Rubik (лицензия SIL OFL 1.1) подключены из npm-пакетов `@fontsource-variable`, а не из Google Fonts. Плагин `vite-plugin-singlefile` упаковывает весь сайт в один HTML.

## Структура

- `index.html` — готовая игра в одном файле (создаётся сборкой)
- `dev.html` — исходная страница для разработки
- `src/App.tsx` — меню, экран игры, оверлеи паузы и победы
- `src/game/engine.ts` — игровая логика и отрисовка
- `src/game/config.ts` — баланс, пути, клавиши, зона строительства
- `src/game/audio.ts` — звуковые эффекты
- `src/ErrorBoundary.tsx` — показывает ошибку вместо пустого экрана
- `src/fonts.css` — локальные шрифты
